# Elevate with Kait

The official website for Elevate with Kait, built with Next.js and designed for deployment on Vercel.

## Pages

- Home
- Offers
- Retreats
- Weekly Classes
- About Kaitlyn
- Contact and Booking

Retreat and weekly class information is pulled from Kaitlyn's public Google Sheet and refreshed every five minutes. Contact forms and scheduling areas are ready for GoHighLevel embeds when they become available.

## Local development

```bash
npm install
npm run dev
```

Before publishing, run:

```bash
npm run lint
npm run build
```
